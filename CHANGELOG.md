# Changelog

## 0.1.3

- Use the Markdown body typeface for fifth- and sixth-level headings instead of the UI sans stack.
- Strengthen fourth-level headings with darker text, heavier weight and a clearer two-pixel guide rule.
- Keep the editor canvas and print output on a pure white paper background.

## 0.1.2

- Expand the fixed 720px writing column to a responsive layout capped at 1180px.
- Remove inherited box shadow, text shadow and filters from inline code.

## 0.1.1

- Remove SiYuan's inherited secondary bar from blockquotes and keep a single fine guide rule.
- Render editor tables with real table layout so columns fill the available width.
- Replace yellow table surfaces with white body cells and a neutral-gray header.
- Remove the red-circle annotation mapping from the SiYuan adapter.

## 0.1.0

- Preserve the local Typora Kami CSS as an unchanged source asset.
- Adapt Kami selectors to SiYuan Protyle without restyling the application shell.
- Change only the writing-paper background from `#fff8ed` to `#ffffff`.
